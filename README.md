# 🚗 Kodkod Car Store - חנות רכבים אונליין

אפליקציית ווב אינטראקטיבית להצגת קטלוג רכבים, סינון לפי קטגוריות וניהול עגלת קניות בזמן אמת. הפרויקט פותח במסגרת תרגול עבודה שיתופית בצוות עם Git ו-GitHub.

## ✨ פיצ'רים עיקריים
* **קטלוג רכבים דינמי:** הצגת מגוון דגמי רכבים כולל תמונות, מפרט טכני, שנת ייצור ומחיר.
* **סינון לפי קטגוריות:** אפשרות לסינון מהיר בין רכבים חשמליים, רכבי פנאי (SUV), רכבי ספורט ויוקרה ומשפחתיות.
* **ניהול עגלת קניות (`addToCart` & `removeFromCart`):** הוספת רכבים לעגלה, הסרת פריטים וחישוב אוטומטי של כמות הפריטים והסכום הכולל לתשלום.
* **ממשק RTL מלא:** עיצוב רספונסיבי מותאם לעברית מימין לשמאל.

## 🛠️ טכנולוגיות
* **HTML5** – מבנה העמוד והקטלוג
* **CSS3** – עיצוב רספונסיבי וכרטיסיות רכבים
* **JavaScript (Vanilla)** – ניהול נתונים, סינון דינמי ולוגיקת עגלת קניות
* **Git & GitHub** – ניהול גרסאות, עבודה בענפים (Branches), בקשות משיכה (Pull Requests) וסקירת קוד הדדית (Code Review)
